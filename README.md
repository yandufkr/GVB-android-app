# EEP Gender-Based Violence Reporting System – Android App

Official Android mobile application for the Ethiopian Electric Power (EEP) Gender-Based Violence Reporting System.

## Version
1.0.0

## Features
- Secure staff authentication
- Gender-Based Violence incident reporting
- Incident tracking
- Notifications
- English and Amharic language support
- Role-based access control

## Installation
Download the APK from the Releases section and install it on your Android device.

## Organization
Ethiopian Electric Power (EEP)
